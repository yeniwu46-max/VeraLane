# 演示与答辩提纲

这份文档是录制与答辩脚本，不是已经录好的视频或最终 PPT。系统默认规则演示，数据全部虚构；三条联网验收样本曾因 HTTP 401 降级，不能当作模型成功率。

## 4 分 40 秒主视频

| 时间 | 操作与台词重点 | 屏幕证据 |
| --- | --- | --- |

| 0:20–1:05 | 问“上个月餐饮花了多少”，打开交易，再查看分类或期间变化。 | 137 元及 8 月交易证据；口径与覆盖范围 |

不要在已有取消记录的数据库反复重演“首次取消”；可以保留回执展示，或另设新的 `VERALANE_DB_PATH` 创建新演示数据。先在界面核对业务时钟，不要在录制中隐式重置。

## 不超过 10 分钟答辩：建议 9 分钟

| 页 | 时长 | 内容 |
| --- | --- | --- |
| 1 | 0:40 | 用户问题、项目定位、为什么强调可核对的执行 |
| 2 | 0:50 | 六类业务覆盖与当前模拟边界 |
| 3 | 1:00 | 自然语言 → 受限计划 → 银行工具 → 确认 → 执行/回执架构 |
| 4 | 1:20 | 支出优化跨场景演示：证据、用户选择、真实目标差额 |
| 5 | 1:00 | 整数分、AA余数、产品份额精度与账单可比期间算法 |
| 6 | 1:10 | 黄/红授权、快照绑定、验证期限与会话隔离 |
| 7 | 1:00 | 预留账本、周期任务、幂等、事务与故障回滚 |
| 8 | 1:00 | 实际测试和页面证据；真实模型与规则结果分别说明 |
| 9 | 1:00 | 已知风险、真实银行适配/登录/真实验证/合规接入的后续工作 |

核心回答：

- “智能在哪里”：受限语句解析、缺参澄清、同名消歧、可复算统计、证据驱动的候选计划与可执行工具串联。当前离线模式能力有限，不能宣称理解所有自由表达。
- “为什么不让模型直接改余额”：模型输出可能不完整或错误，所有金额、权限与执行条件必须由确定性工具复核。
- “重试会不会重复扣款”：同一操作 ID 返回既有结果；子项 ID、交易唯一约束和事务保持账本与任务状态一致。
- “是真实银行级安全么”：不是。当前共享虚构账户、会话 ID 与展示验证码仅供原型演示，真实认证、密钥管理、风控与清算尚未接入。
- “20元预算如何控制”：本地持久化限制调用数/令牌/并发，配置单价才估算费用；平台既有消费未知，不能把本地估算当余额。
