# VeraLane 技术更新记录 — 2026-10-04

## 今日更新

### 账单与转账历史的自然时间范围

- 账单问答新增“上周”和“最近/近/过去 N 天”窗口。上周按周一至周日计算；近 N 天包含当前演示业务日，N 限制为 1–90。
- 短窗口按相同天数与紧邻的前一窗口对比，报告返回查询起止日期、交易证据和比较区间。
- 转账历史查询采用相同日期语义。两类只读查询都使用演示业务日期。
- 宽泛或有歧义的表达（例如“最近”“上上周”“上周末”“前两个月”）以及越界天数会要求澄清，不会退化为无日期筛选的全历史查询。

### 支出优化计划的证据提示

- 当前期没有流水或比较基期没有流水时，计划摘要明确说明无法判断支出变化原因。
- 比较页展示基期日期、匹配流水笔数和报告限制；有基期证据时才显示变化金额及分类贡献，并说明金额贡献不等于消费动机。

### 技术材料一致性

- AA 首版验收记录现在明确标为历史快照，并链接到后来新增的多人结算、退款、分次回款、按菜品分摊、本机 OCR 和站内提醒说明。
- 技术文档补充账单短周期查询的算法口径；阶段执行记录及 README 链接更新。

## 算法与安全边界

- 日期范围由确定性规则解析；账单比较双方等长，使用整数分汇总。
- 只读历史查询不生成业务 action、不改余额；对无法可靠解析的时间先澄清。
- 账单解释仅根据已保存的模拟流水，不能从金额变化推出消费动机。所有账户、交易和协议均为虚构演示数据。
