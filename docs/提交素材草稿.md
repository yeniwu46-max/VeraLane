# VeraLane 提交素材草稿

## 项目简介（200 字以内）

VeraLane 是一款可核验的 AI Banking 智能体。用户以自然语言提出转账、账单分析与订阅管理需求，系统借助 DeepSeek 提取意图，由确定性银行工具核对对象、金额与权限；低风险查询直接完成，资金或协议变更先展示计划并请求确认，高风险操作触发强验证边界。模拟账本、交易来源和审计轨迹让每一步执行都有据可查。

## 十分钟答辩建议结构

| 时长 | 内容 |
| --- | --- |
| 1 分钟 | 用户痛点：银行操作跨入口、口语表达模糊、关键动作缺乏可核验依据 |
| 1 分钟 | VeraLane 定位与三条主场景 |
| 2 分钟 | 架构与受限意图、确定性工具、确认门槛 |
| 3 分钟 | 演示：账单 → 重名转账澄清 → 确认后账本变化 → 订阅取消 |
| 2 分钟 | 权限分级、幂等、审计、异常复核提示 |
| 1 分钟 | 评测结果、已知风险与后续路线 |

## 五分钟视频建议镜头

1. 15 秒：一句话解释产品定位和“Banking, verified.”。
2. 75 秒：账单统计与异常金额提示，展示来源交易 ID。
3. 90 秒：同名澄清、转账计划、确认前后余额和审计变化。
4. 60 秒：订阅查询与取消，展示协议状态更新。
5. 30 秒：红级转账拦截。
6. 30 秒：架构、测试与开源仓库入口。

录制前需确保镜头中的每项能力确已实现、文案与代码版本一致。仓库链接、实测指标和团队分工待最终版补入。
